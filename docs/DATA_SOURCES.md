# Data Sources

## Dataset

**Adult Income** (OpenML id 1590, version 2), mirroring the UCI Machine Learning Repository /
1994 US Census Bureau extract.

- **Canonical URL:** https://www.openml.org/d/1590
- **License:** Public domain (US Census Bureau source data). UCI/OpenML redistribution terms:
  free for research/educational use, no warranty, cite source. Verified at the source page, not
  assumed from the dataset's name.
- **Access date / checksum:** recorded in `research/data/raw/MANIFEST.json`, regenerated by
  `research/ingest/fetch_adult.py` on every fetch (provider, URL, version, SHA-256).
- **Size:** 48,842 rows total; stratified 80/20 train/test split (seed 42) gives 36,177 train /
  9,045 test rows.
- **Task:** binary classification, predict whether reported income exceeds $50K/year.

Full field-by-field reasoning (actionable vs. immutable, why `fnlwgt` and `education` are dropped)
is in `specifications/DATA_CONTRACT.yaml`.

## Known limitations of the data itself

- **1994 data.** Income thresholds and occupational categories reflect that period's economy, not
  a current one. Every historical number the app shows is labeled as such.
- **22% train/test leakage.** Once the `fnlwgt` sampling-weight column is dropped, 1,977 of 9,045
  test rows exactly duplicate a training row on the remaining columns. Disclosed in
  `model_manifest.json`'s `leakage_check` field and `docs/LIMITATIONS.md`, not hidden or silently
  deduplicated. Adult's AUROC is well-established in the literature at 0.90-0.93 independent of
  this specific split, so the effect is judged unlikely to be large; a grouped split that removes
  the duplicates is recorded as the honest fix, not applied here.

## Models

Two real classifiers, trained in `research/models/train.py`:

| Model | Test AUROC | Test Brier | Live in-browser evaluator? |
|---|---|---|---|
| Logistic regression | 0.9045 | 0.1049 | Yes (`src/engine/model.ts`, exact port) |
| Gradient-boosted trees (`HistGradientBoostingClassifier`) | 0.9260 | 0.0916 | No -- tree internals are not public sklearn API the way logistic coefficients are. Shows only its real precomputed test-set probability, never a perturbed/fabricated one. |

Cross-validated (5-fold stratified) during training; both CV and held-out test metrics are
recorded in `model_manifest.json` and independently re-derivable from `data/precomputed/
full_test_fixture.json` (the 9,045-row research-only fixture) -- see
`tests/unit/test_reference.py`'s reconciliation tests, which recompute AUROC/PR-AUC/Brier and
every threshold/calibration row directly from raw per-row data rather than trusting `train.py`'s
own computation.

## Fixtures shipped to the browser

`public/data/precomputed/`: `model_manifest.json` (coefficients, scaler params, categories --
everything the TS port needs to reproduce the logistic model exactly), `test_fixture.json` (a
~300-case stratified sample across predicted-probability deciles, for the case browser --
metrics/calibration/threshold fixtures use the FULL 9,045-row test set, not this sample),
`threshold_sweep.json` (99 threshold rows x confusion counts), `calibration.json` (10 reliability
bins). All regenerated by `research/models/train.py`, never hand-edited.
